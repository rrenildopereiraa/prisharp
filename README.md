# Prisharp

See the tech behind any site, in one click.

| App                                |                                            |
| ---------------------------------- | ------------------------------------------ |
| [`apps/extension`](apps/extension) | The Chromium extension                     |
| [`apps/web`](apps/web)             | prisharp.com, one page built with Yumma UI |

## Develop

The workspace runs on [Vite+](https://viteplus.dev).

```bash
pnpm install
pnpm dev        # the site
pnpm ready      # check, test and build everything
```
