# Prisharp

See the tech behind any site, in one click.

| App                                |                        |
| ---------------------------------- | ---------------------- |
| [`apps/extension`](apps/extension) | The Chromium extension |
| [`apps/web`](apps/web)             | The docs site          |

## Technologies

Each one is detected only from evidence it alone leaves, and the popup shows that evidence. Missing one? [Request it](https://github.com/rrenildopereiraa/prisharp/issues/new?template=technology.yml), or add it yourself as [`apps/extension`](apps/extension#add-a-technology) explains.

## Develop

The workspace runs on [Vite+](https://viteplus.dev).

```bash
pnpm install
pnpm dev        # the site
pnpm ready      # check, test and build everything
```
