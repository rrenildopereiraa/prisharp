## Install

Prisharp is not on the Chrome Web Store yet, so it loads from source.

1. Clone the repository.

   ```bash
   git clone https://github.com/rrenildopereiraa/prisharp
   ```

2. Open `chrome://extensions` and turn on **Developer mode**.
3. Click **Load unpacked** and pick `prisharp/apps/extension`.
4. Pin Prisharp, open any site and click it.

It runs in Chromium browsers, such as Chrome, Edge, Brave and Arc.

## How it works

Every technology leaves evidence in what it ships to the browser: a global it defines, an attribute it writes, a path it serves its files from, a banner at the top of its CSS. Prisharp keeps those fingerprints as data and weighs them.

1. **Collect.** On click, Prisharp reads the page once: its globals, its elements, the files it loaded, its `<meta>` tags, its response headers, and its stylesheets and entry scripts as text.
2. **Score.** Each signal weighs 100, and a weak one 50. A technology shows from 100, so one weak hint is never enough.
3. **Relate.** A technology can imply what it is built on, as Next.js implies React, or need partners to count, as Yumma UI needs Yumma CSS and Base UI.

Versions come from the evidence itself: `window.next.version`, the `ng-version` attribute, the banner Tailwind CSS writes at the top of its stylesheet.

## Privacy

Prisharp runs only when you click it, and only on that tab. It asks for `activeTab` and `scripting`, and for no sites.

What it reads stays in your browser. Its one outside request is a favicon from Google, for a technology without a bundled logo, and it names that technology's site, never the page you are on.

## Add a technology

Fingerprints live in `apps/extension/src/technologies.js`, as data:

```js
{
	id: "nextjs",
	name: "Next.js",
	website: "https://nextjs.org",
	category: "Framework",
	implies: ["react"],
	signals: [
		{ js: "next.version", version: true },
		{ resource: /\/_next\/static\// },
		{ header: ["x-powered-by", /next\.js/i] },
	],
}
```

Check the evidence against the package itself: install it, build a small app and look at what reaches the browser. Then open a pull request.
